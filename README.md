## 💻 Projetos em Destaque

### 🏦 Sistema Bancário em Python
Um projeto prático desenvolvido para simular operações bancárias básicas através do terminal:
* **Funcionalidades:** Depósito, Saque (limite de 3 saques diários) e Consulta de Saldo.
* **Estrutura:** Utilização de laços de repetição (`while`), funções e validações de fluxo.
